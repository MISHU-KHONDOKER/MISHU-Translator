MISHU Translator: iPhone setup

One-time setup. iPhone needs HTTPS before a web page can use the microphone, so first it must trust your PC's certificate.

  1. Open this page in Safari (not Chrome or WeChat).
  2. 1. Download certificate Tap Allow when it asks to download a configuration profile.
  3. Open Settings → Profile Downloaded (near the top) → Install → enter passcode → Install.
  4. Open Settings → General → About → Certificate Trust Settings and switch on MISHU Translator Local CA.
  5. 2. Open the translator
  6. In Safari tap the Share button → Add to Home Screen. Then open it from the Home Screen like an app.

Your iPhone and this PC must be on the same Wi-Fi.
